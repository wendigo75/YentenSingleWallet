WALLET USAGE HELP

A quick description of the buttons on the page

Wallet Buttons

  • CREATE WALLET - Generates a new wallet locally from a BIP39 recovery phrase. No transaction is made.
  • IMPORT A WALLET - Derives an address from a 12-word BIP39 phrase using this project's derivation path, or imports the exact address from a Yenten WIF key. A BIP39 passphrase is optional.
  • OPEN A WALLET - Checks the password set during import before opening the saved wallet.
  • REMOVE A WALLET - Removes the saved wallet and recovery data from this app's local browser profile after confirmation.
  • VIEW - Displays saved wallet recovery data.
  • HISTORY - Shows confirmed and unconfirmed transactions for the currently open wallet address only.

Interface Buttons

  • 🏳‍🌈 LANGUAGE BUTTON - Toggles the interface language between native English and your computer system language.
  • ❓ HELP BUTTON - Opens this popup window.
  • ℹ️ INFORMATION BUTTON - Opens the privacy and safety guidelines.
  • 🤝 CREDITS BUTTON - Displays the mentions and acknowledgments for the original code repositories and authors.

PRIVACY & SECURITY STATEMENT

What is a Non-Custodial Wallet?

A non-custodial wallet means that you have absolute and total control over your funds and private keys. Cryptocurrency assets are never stored inside this website or on centralized servers; they reside permanently on the decentralized Yenten Coin blockchain network.

Local Storage and Privacy

Wallet secrets are encrypted with your wallet password and stored locally in this app's browser profile; they are not sent to the wallet server. The Windows app keeps this profile between launches. Phrase recovery uses the path m/44'/125'/0'/0/0. Balance and transaction history lookups send only the public address to the configured Yenten API. GitHub Pages is static hosting and needs a separate compatible API endpoint; app.py provides the endpoint for local testing only.

⚠️

CRITICAL RESPONSIBILITY DISCLOSER.

Never enter a recovery phrase or private key into a website you do not trust. Keep an offline backup of the original recovery data. The app cannot recover wallet data if its local browser profile is deleted or its password is lost.

⚠️

Best Crypto Practices:

  • Always write down your 12-word recovery phrase on physical paper and store it in a secure place offline.
  • Never take digital screenshots, save keys in text files on your computer, or share them on cloud services.
  • Double-check that the application is running locally or on the official secure address before introducing data.
